#สรุปความรู้เรื่อง GitHub และ DevOps
1. Git คือเครื่องมือสำหรับควบคุมเวอร์ชันของไฟล์และชอร์สโค้ด
2. Github.ioร์มออนไลน์สำหรับจัดเก็บ Repository และทำงานร่วมกัน 
3. Repository คือพื้นที่จัดเก็บไฟล์โครงงานและประวัติการเปลี่ยนแปลง
4 Commit คือการบันทึกสถานะของไฟล์งานในช่วงเวลาหนึ่ง 
5. การ Push ไฟล์ขึ้น Github.ioให้สามารถส่งงาน ตรวจสอบงาน และทำงานร่วมกันตามแนวคิด DevOps ได้สะดวกขึ้น
